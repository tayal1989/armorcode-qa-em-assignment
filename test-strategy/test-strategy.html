High-Risk Services & Flows

Codebase vulnerability analysis across polyglot microservice boundaries.

Checkout Orchestration Flow

Critical Risk

Coordinates a long chain of synchronous gRPC calls across C#, Go, C++, PHP, and Node.js.

Cascading Timeout Storms Without bulkhead or circuit-breaker protection, an execution halt in Payments halts the Go routines in Checkout, quickly depleting connection pools.
Transactional State Desynchronization Lacks Saga orchestration. If shipping fails after card authorization, the user is charged for an order that cannot be fulfilled.
Compliance Attributes Leakage Sets plaintext credit card number and CVV as trace span attributes, propagating PCI leaks directly to exporters.

Financial Blast Radius

Critical Risk

Node.js Payments service performing mock currency transaction calculations.

Numerical Floating Rounding Receives Money models in fractional nano-units. Rounding discrepancies between C++ math conversion and JS parsing can under- or over-charge.
Asynchronous Fraud Loop Timing The Java fraud service evaluates events *post-checkout*. Mallory (fraudster) completes payment and shipping confirms before fraud is flagged, incurring heavy chargeback bills.

State Synchronization

High Risk

Valkey cart caching and Postgres database catalog management.

Pricing Race Conditions Product catalog prices recalculated dynamically at checkout. Price changes in DB while cart is open result in customer disputes at payments.
Valkey Volatile Storage Eviction Carts reside in volatile Valkey cache. Memory pressure can drop cart items, disrupting user sessions.

Unit & Component Testing

Isolates pure business code rules (like tax percentages, ad selectors, or currency conversions) from external dependencies using stubs and mock frameworks.

Target Ratio 40%
Primary Tooling xUnit / GoMock / Moq / PyTest
Execution Phase Local Dev & PR Build Gates

Deliberate QA Gaps (Un-Automated Areas)

Jaeger/Grafana UI Verifications

Visual testing of tracing dashboards is highly brittle. We bypass UI testing and instead enforce schema checks using `weaver registry check` directly in pipeline logs.

Visual Recommendation Element Diffing

Dynamic recommendation content results in high test flakiness. We skip visual checking and verify structurally via DOM element accessibility checks.

Sandbox Third-Party Gateways

To prevent dependency blocks, sandbox billing interfaces are replaced with local, deterministic mock stubs in daily pipelines.

Human vs. Agent Boundaries

To ensure reliability, security, and human compliance, we establish clear operational limits for agent actions.

Execution Scope Autonomous Agent Boundaries Human Guardrails & Decisions
Payload Design Autonomously builds edge cases, boundary numbers, empty arrays, and schema types derived from OpenAPI specs. Defines core business-critical flows and transaction chains (e.g. valid card checkout sequence).
Test Assertion Engine Generates schema validation rules (AJV), verifying exact type checking and status code compliance. Establishes critical business logic rules (e.g. discount policy, complex currency conversions).
Failure Recovery & Mocks Parses execution logs, catches HTTP 404/405 faults, and replaces failed endpoints with schema-accurate mock responses. Reviews flagged functional errors indicating real regressions, and coordinates environment setups.
Governance & Security Performs sanitization verifications on identifiers and formats. Grants code sign-off, approves security policy overrides, and triggers deployment.
🛡️

Static Guardrails

Verifies TypeScript code syntax before runtime. Playwright/SWC compiler ensures the code conforms to structural grammar rules, preventing execution of broken scripts.

The generator uses the local `tsconfig.json` configuration specifying strict type checkers (`strict: true`) to resolve data assignment faults during development.

💡 Guardrail Summary

Static guardrails enforce syntax, types, and formatting prior to triggering container calls, shielding testing pipelines from generating syntactical noise.

⚡

Dynamic Guardrails & Hallucination Mitigation

The tests are compiled against containerized instances representing mock architectures or live local containers, verifying responses with minimal flakiness.

Assertions restrict status codes (e.g. only 200 / 404 / 405) and schema shapes using AJV. By disabling additional properties (`additionalProperties: false`), any unexpected API payload immediately triggers a validation failure.

🛡️ Hallucination Control

Agent asserts responses *only* against defined schemas within the OpenAPI contract, preventing the agent from inventing fields or mock responses.
